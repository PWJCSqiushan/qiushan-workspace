# 理财投资

`/investment` 与任务流水、时间调度、生活账本平级，复用既有登录。匿名用户不能访问投资 API；私人和演示空间分别存储。页面用于研究、条件预案和手工成交记录，用户在自己的交易软件执行操作。

前端从用户自有的本机投资项目增量移植，使用 React 和 ECharts；后端为 TypeScript Worker API 和 D1，不依赖 Python 服务或 localhost iframe。投资模块的版本、操作回执和备份独立于原有三模块。

公开行情适配器只请求验证过的来源域名，不携带用户账户凭据。价格、历史、净值分别保存来源、日期、单位和新鲜度。失败保留历史缓存并显示状态；缺失值保持 null。场外基金展示正式净值，报告仍需匹配品种、行情快照和个人条件。

开账登记现金和持仓基准；未知实际成本保持 null。券商展示的摊薄成本可为负数，仅用于展示。入金和提现改变本金，不作为利润。场外备用资金未实际转入前不计入券商现金。费用未核验时保留未知标记，基金待确认记录需要实际确认后才能变成持仓。

写入需要当前版本和唯一操作标识。网络失败保留未提交表单；版本冲突要求重新核对云端版本。空间切换会隔离请求和表单。恢复备份需要校验所属身份、空间和内容摘要，并先保存恢复前快照。

公开仓库只包含源码、第三方说明和独立合成测试数据。真实账户、报告、凭据和验收导出放在忽略的 private 目录，并只迁移到已授权的私人空间。行情访问在本机成功不能证明 Worker 出口同样可用，实际生产刷新验收单独记录。

参考范围沿用本机项目的第三方说明：AKShare 的公开字段和请求结构、daily_stock_analysis 的缓存降级思路、portfolio-tracker 的看板分类。不复制未确认许可的交易执行代码或 GPL 项目源码。各依赖保持其原许可；开源代码许可不代表上游数据服务的稳定性或再分发许可。
